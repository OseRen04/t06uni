# t06：キャンパス授業ナビ 中間報告改良版

## キャッチフレーズ

時間割から、教室の入口まで迷わず行ける。

---

## 解くべき課題

大学内の授業移動では、時間割で教室番号は分かっていても、実際にどの建物へ行き、建物内でどう進めばよいか分からないことがある。

特に新入生や初めて使う教室が多い学生は、授業開始前の短い時間で迷いやすい。解くべき課題は、単に地図を見せることではなく、学生が次の授業に間に合うように教室入口まで迷わず進める状態を作ることである。

---

## 対象ユーザー

- 大学内で授業間を移動する学生
- キャンパスや建物の位置にまだ慣れていない学生
- 建物に着いた後、講義室までの行き方に不安がある学生

---

## 提案する体験

このアプリでは、学生が時間割から授業を選ぶだけで、建物までの案内と建物内の案内を続けて確認できる。

| 場面 | 支援すること |
| --- | --- |
| 授業を探す | 時間割や検索から目的の授業を見つける |
| 建物へ向かう | 現在地から目的の建物までの道順と徒歩時間を確認する |
| 建物内を進む | フロア図と写真を見ながら講義室入口まで進む |
| 到着する | 講義室入口の写真で目的地を確認する |

---

## 最小限必要な機能

| 機能 | 内容 |
| --- | --- |
| 時間割表示 | 曜日・時限ごとに授業を表示する |
| 授業検索 | 授業名、教室番号、建物名から目的の授業を探す |
| 授業追加 | 自分の授業を時間割に追加する |
| 建物案内 | 目的の建物までの道順と徒歩時間を表示する |
| フロア案内 | 建物内で講義室入口まで段階的に案内する |

---

## 利用フロー

1. アプリを開き、時間割を見る。
2. 目的の授業を選ぶ。
3. キャンパスマップで、建物までの道順を確認する。
4. 建物に着いたら、フロア案内へ進む。
5. 写真とフロア図を確認しながら講義室入口へ向かう。
6. 講義室入口を確認して到着する。

---

## 案内に使う情報

| 情報 | 役割 |
| --- | --- |
| 授業情報 | 授業名、曜日、時限、建物、階、教室番号を確認する |
| 建物情報 | キャンパス内で目的の建物を示す |
| フロア情報 | 建物内で現在地と目的地を示す |
| 写真 | 実際の場所と画面の案内を照らし合わせる |

---

## 現在のプロトタイプ範囲

現在は、時間割から授業を選び、キャンパスマップで建物まで案内し、学部棟1階の104講義室入口まで案内する流れを確認できる。

今後は、ほかの建物や教室にも対応できるように、案内できる場所を増やしていく。
