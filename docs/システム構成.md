# システム構成

## 目的

このドキュメントでは、利用者が何を入力し、アプリがどのように案内を組み立て、利用者に何を返すかを整理する。

現時点では、保存先や外部連携の設計ではなく、授業案内アプリとして必要な画面、情報、案内の流れに絞って説明する。

## 全体像

このアプリは、次の4つの画面を中心に構成される。

| 画面 | 役割 |
| --- | --- |
| 時間割画面 | 利用者が目的の授業を探し、授業案内を始める入口になる。 |
| 授業追加画面 | 時間割にない授業を利用者が追加できるようにする。 |
| キャンパスマップ画面 | 現在地から授業が行われる建物までの行き方を示す。 |
| フロア案内画面 | 建物に入ってから講義室入口までの進み方を示す。 |

全体の関係は次の通りである。

| 利用者 | 画面 | 案内に使う情報 | 表示される結果 |
| --- | --- | --- | --- |
| 授業を探す | 時間割画面 | 授業名、曜日、時限、建物、教室番号 | 時間割、検索結果 |
| 授業を追加する | 授業追加画面 | 利用者が入力した授業情報 | 追加された授業カード |
| 建物まで向かう | キャンパスマップ画面 | 建物の位置、現在地、徒歩時間、道順 | 建物までのルート |
| 建物内を進む | フロア案内画面 | フロア図、目印写真、案内文 | 講義室入口までの案内 |

## 入力・処理・出力

| 場面 | 利用者が入力するもの | アプリが行うこと | 利用者に返すもの |
| --- | --- | --- | --- |
| 時間割を見る | なし | 登録済みの授業を曜日・時限ごとに並べる。 | 時間割グリッド、授業カード |
| 授業を検索する | 授業名、教室番号、建物名、担当教員などの言葉 | 入力された言葉に合う授業を探す。 | 検索結果一覧、一致件数、該当なしの表示 |
| 授業を追加する | 授業名、担当教員、曜日、時限、建物、階、教室番号 | 必要な項目が入力されているか、同じ時間に別の授業がないかを確認する。 | 追加後の時間割 |
| 授業を削除する | 編集中に削除ボタンを押す | 選ばれた授業を時間割から外す。 | 削除後の時間割 |
| 授業を選ぶ | 時間割カードまたは検索結果を押す | 選ばれた授業をもとに、次の案内画面へ進む。 | キャンパスマップ画面 |
| 建物までの案内を見る | キャンパスマップ画面を見る | 授業が行われる建物を目的地として、現在地からの行き方を表示する。 | 建物までの経路、目的地の印、徒歩時間、授業情報 |
| 建物内の案内へ進む | 「建物に入る」ボタンを押す | 建物内の案内画面へ切り替える。 | フロア案内画面 |
| 建物内を進む | 「次へ進む」「戻る」を押す | 現在の案内段階に合わせて、地図上の位置、道順、写真、説明文を切り替える。 | フロアマップ、目印写真、説明文、到着ボタン |

## 画面ごとの構成

### 時間割画面

時間割画面では、利用者が授業を探しやすいように、曜日と時限に沿って授業を配置する。授業カードには、授業名、建物、階、教室番号を表示する。

検索欄では、授業名、教室番号、建物名、担当教員などの言葉から授業を探せる。目的の授業を押すと、建物までの案内に進む。

### 授業追加画面

授業追加画面では、利用者が新しい授業を時間割に加える。

入力する内容は、授業名、担当教員、曜日、時限、建物、階、教室番号である。授業名と教室番号は案内に必要な情報として扱う。同じ曜日・時限にすでに授業がある場合は、重複して追加できないようにする。

### キャンパスマップ画面

キャンパスマップ画面では、選ばれた授業の建物を目的地として表示する。

利用者は、現在地から建物までの道順、徒歩時間、目的地の位置を確認できる。画面下部には、選んだ授業の名前、建物、階、教室番号、授業時間を表示する。

### フロア案内画面

フロア案内画面では、建物に入ってから講義室入口までの流れを、段階ごとに表示する。

現在のプロトタイプでは、次の3段階で案内する。

| 段階 | 案内内容 | 利用者が確認すること |
| --- | --- | --- |
| 1 | 学部棟の正面玄関 | 建物の入口に着いているか |
| 2 | エレベーター前 | 建物内で次に進む場所が合っているか |
| 3 | 104講義室入口 | 目的の講義室に着いたか |

## 案内に使う情報

このアプリでは、利用者に案内を返すために、次の情報を使う。

| 情報の種類 | 内容 | 使い道 |
| --- | --- | --- |
| 授業情報 | 授業名、担当教員、曜日、時限、建物、階、教室番号 | 時間割表示、検索、案内先の決定 |
| 建物情報 | 建物名、キャンパス内の位置、現在地からの道順、徒歩時間 | キャンパスマップでの案内 |
| フロア情報 | 部屋の位置、通路、目的地、現在位置 | 建物内での案内 |
| 写真 | 正面玄関、エレベーター前、講義室入口 | 実際の場所と画面の案内を照らし合わせる |

## 結果として利用者に返すもの

利用者は、アプリを使うことで次の結果を得られる。

- 次に向かう授業を時間割からすぐに見つけられる。
- 授業が行われる建物と教室番号を確認できる。
- 現在地から建物までの移動ルートと徒歩時間を確認できる。
- 建物に入ってから講義室入口まで、写真と地図を見ながら進める。
- 最後に「到着！完了」で目的地に着いたことを確認できる。

## 現在の範囲

現在のプロトタイプでは、授業の追加・削除はアプリを開いている間だけ反映される。正式な保存方法や外部サービスとの連携は、今後の検討範囲とする。

また、建物内の案内は学部棟1階の104講義室を例として作成している。今後、ほかの建物や教室にも対応する場合は、授業ごとに適切な建物内案内を表示できるようにする。
