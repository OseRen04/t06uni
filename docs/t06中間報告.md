# t06：キャンパス授業ナビ

チーム t06：メンバー名を記入

## 時間割から、教室の入口まで迷わず案内する

大学の授業移動では、「次の授業がどの建物か」「建物の中でどこへ進めばよいか」が分からず、移動に不安や時間のロスが生まれることがある。キャンパス授業ナビは、時間割から授業を選ぶだけで、建物までの道順と、建物内で講義室入口へ向かう流れを続けて確認できるアプリである。

---

## 対象ユーザー・利用場面・解くべき課題

対象ユーザーは、大学内で授業間を移動する学生である。特に、新入生、初めて使う教室が多い学生、広いキャンパスや複数の建物に慣れていない学生を想定している。

利用場面は、授業開始前や休み時間など、次の講義へ移動する必要があるタイミングである。学生は時間割で授業名や教室番号を確認できても、実際には次のような点で困ることがある。

- 建物名は分かるが、キャンパス内でどこにあるか分からない。
- 建物に着いても、講義室までの進み方が分からない。
- 教室番号だけでは、階や入口、目印になる場所を想像しにくい。
- 授業開始まで時間が少ないと、道に迷うこと自体が大きな不安になる。

このプロダクトで解くべき課題は、単に地図を見せることではなく、「次の授業に間に合うように、学生が迷わず教室入口まで進める状態を作ること」である。

---

## 解決の方向性とユーザー体験

解決の方向性は、時間割、キャンパスマップ、建物内案内をひと続きの体験としてつなぐことである。学生は授業名や教室番号を別々に確認するのではなく、時間割から授業を選ぶだけで、目的地までの案内を始められる。

使う前、使う時、使った後の体験は次のように変化する。

| 場面 | 従来の困りごと | このプロダクトで目指す体験 |
| --- | --- | --- |
| 使う前 | 時間割を見ても、建物や教室までの行き方がすぐ分からない。 | 時間割から目的の授業を選ぶだけで案内を始められる。 |
| 使う時 | 建物までは行けても、建物内で迷いやすい。 | キャンパスマップとフロア案内を順番に確認しながら進める。 |
| 使った後 | 目的地に着いたか不安が残る。 | 講義室入口の写真を見て、到着したことを確認できる。 |

## MVPと開発予定の機能

MVPでは、学生が「時間割から授業を選び、建物まで行き、講義室入口に着く」までの体験を成立させることを最優先にする。

### MVPで扱う必須機能

| 機能 | 内容 | 目的 |
| --- | --- | --- |
| 時間割表示 | 曜日・時限ごとに授業を表示する。 | 次に向かう授業を見つけやすくする。 |
| 授業検索 | 授業名、教室番号、建物名、担当教員から授業を探す。 | 授業数が増えても目的の授業にすぐたどり着けるようにする。 |
| 授業追加 | 授業名、曜日、時限、建物、階、教室番号を入力して追加する。 | 利用者自身の時間割に合わせられるようにする。 |
| 建物までの案内 | 現在地から目的の建物までの道順と徒歩時間を表示する。 | キャンパス内で迷わず建物へ向かえるようにする。 |
| 建物内の案内 | フロア図、現在位置、写真、説明文で講義室入口まで案内する。 | 建物内でも目的地まで進めるようにする。 |

### 発展機能として検討するもの

- 複数の建物や複数階への対応
- ほかの講義室への案内切り替え
- 食堂、図書館、事務室など授業以外の目的地への案内
- 授業開始時刻に合わせた移動リマインド
- 混雑しにくいルートや雨の日のルートの提示

### 今回は扱わないもの

現時点では、個人アカウントや長期的な記録管理は主な検討対象にしない。まずは、授業移動の体験そのものが成立するかを確認する。

## 利用フローとシステム構成

利用者は、次の順番でアプリを使う。

1. アプリを開き、時間割画面を見る。
2. 今日の授業、または検索欄から目的の授業を探す。
3. 時間割にない授業は、授業追加画面から登録する。
4. 目的の授業を選ぶ。
5. キャンパスマップ画面で、現在地から建物までの道順と徒歩時間を確認する。
6. 建物に着いたら、フロア案内画面へ進む。
7. 正面玄関、エレベーター前、講義室入口の順に案内を確認する。
8. 講義室入口に着いたら、到着として案内を終える。

### 画面遷移

| 順番 | 画面 | 利用者がすること | 得られる結果 |
| --- | --- | --- | --- |
| 1 | 時間割画面 | 授業を探す、授業を選ぶ。 | 次に向かう授業を決められる。 |
| 2 | 授業追加画面 | 必要な授業情報を入力する。 | 時間割に新しい授業が追加される。 |
| 3 | キャンパスマップ画面 | 建物の場所と道順を確認する。 | 目的の建物まで移動できる。 |
| 4 | フロア案内画面 | 写真とフロア図を見ながら進む。 | 講義室入口まで到着できる。 |

### 入力・処理・出力

| 利用者が入力するもの | アプリが行うこと | 利用者に返すもの |
| --- | --- | --- |
| 授業名、曜日、時限、建物、階、教室番号 | 授業を時間割に追加し、同じ時間に重複がないか確認する。 | 追加された授業カード |
| 授業名や教室番号などの検索語 | 条件に合う授業を探す。 | 検索結果一覧 |
| 時間割で選んだ授業 | 授業が行われる建物を目的地として表示する。 | 建物までの道順、徒歩時間、授業情報 |
| 「次へ進む」「戻る」の操作 | 建物内の案内段階を切り替える。 | 現在地、次に進む場所、目印写真、説明文 |

### 案内を支える情報

このプロダクトでは、授業案内を成立させるために次の情報を使う。

| 情報 | 内容 | 使われる場面 |
| --- | --- | --- |
| 授業情報 | 授業名、担当教員、曜日、時限、建物、階、教室番号 | 時間割表示、検索、案内先の決定 |
| 建物情報 | 建物の位置、現在地からの道順、徒歩時間 | キャンパスマップでの案内 |
| フロア情報 | 部屋の位置、通路、現在位置、目的地 | 建物内での案内 |
| 写真 | 正面玄関、エレベーター前、講義室入口 | 現実の場所と画面の案内を照らし合わせる |

### 現在のプロトタイプの範囲

現在のプロトタイプでは、時間割から授業を選び、キャンパス内の建物案内へ進み、学部棟1階の104講義室入口まで案内する流れを確認できる。今後は、ほかの建物や教室にも対応できるように、案内対象を広げていく。
