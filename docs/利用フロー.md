# 利用フロー

## 目的

このドキュメントでは、大学内で授業の教室へ向かう利用者が、どの順番でアプリを使い、どの画面を通して目的地にたどり着くかをまとめる。

このアプリは、時間割から授業を選ぶだけで、キャンパス内の建物までの案内と、建物に入ってから講義室入口までの案内を続けて確認できることを目指している。

## 利用のきっかけ

利用者がアプリを使い始める場面は、次のようなときである。

- 次の授業の教室や建物の場所を確認したい。
- 時間割から目的の授業を探したい。
- 新しく決まった授業を時間割に追加しておきたい。
- 建物までは着いたが、建物内で講義室まで迷わず進みたい。

## 全体の流れ

1. 利用者が「次の授業へ移動したい」と思い、アプリを開く。
2. 時間割画面で、今日の授業や検索欄から目的の授業を探す。
3. まだ時間割にない授業の場合は、授業名、曜日、時限、建物、階、教室番号を入力して追加する。
4. 目的の授業を選ぶ。
5. キャンパスマップ画面で、現在地から授業が行われる建物までの行き方と徒歩時間を確認する。
6. 建物に着いたら、フロア案内へ進む。
7. 建物内では、正面玄関、エレベーター前、講義室入口の順に、地図と写真を見ながら進む。
8. 講義室入口に着いたら、到着として案内を終える。

## 画面の流れ

| 順番 | 画面 | 利用者がすること | 次に進む条件 |
| --- | --- | --- | --- |
| 1 | 時間割画面 | 登録済みの授業を見る。必要に応じて授業を検索する。 | 目的の授業を選ぶ |
| 2 | 授業追加画面 | 授業名、曜日、時限、建物、階、教室番号を入力する。 | 「追加する」を押す |
| 3 | キャンパスマップ画面 | 建物の場所、現在地からの道順、徒歩時間を確認する。 | 「建物に入る」を押す |
| 4 | フロア案内画面 | 建物内の現在地、進む方向、目印になる写真を確認する。 | 「次へ進む」を押して案内を進める |
| 5 | 到着 | 講義室入口を確認する。 | 「到着！完了」を押す |

## 利用シナリオ

### シナリオ1: 登録済みの授業へ向かう

1. 利用者はアプリを開き、時間割画面を見る。
2. 今日の曜日・時限、または検索欄から目的の授業を探す。
3. 授業カードを押す。
4. キャンパスマップ画面で、現在地から対象の建物までのルートと徒歩時間を確認する。
5. 建物に着いたら「建物に入る → フロア案内」を押す。
6. フロア案内画面で、正面玄関、エレベーター前、講義室入口の順に案内を見る。
7. 目的の講義室に着いたら「到着！完了」を押す。

### シナリオ2: 新しい授業を追加してから案内を使う

1. 利用者は時間割画面右上の「＋」ボタンを押す。
2. 授業名、担当教員、曜日、時限、建物、階、教室番号を入力する。
3. 同じ曜日・時限に授業がある場合は追加できないため、別の曜日・時限を選ぶ。
4. 「追加する」を押すと、時間割画面に新しい授業が表示される。
5. 追加した授業カードを押し、キャンパスマップとフロア案内を使って目的地まで移動する。

## 画面ごとの役割

| 画面 | 役割 | 利用者に伝えること |
| --- | --- | --- |
| 時間割画面 | 授業を一覧で確認し、目的の授業を選ぶ入口になる。 | 授業名、曜日、時限、建物、階、教室番号 |
| 授業追加画面 | 時間割にない授業を登録する。 | 入力が足りているか、同じ時間に別の授業がないか |
| キャンパスマップ画面 | 建物までの移動を案内する。 | 現在地、目的の建物、徒歩時間、建物までの道順 |
| フロア案内画面 | 建物内で講義室まで案内する。 | 現在いる場所、次に進む場所、講義室入口の確認 |

## 授業案内に使う情報

このアプリでは、授業案内のために次の情報を扱う。

| 情報 | 内容 | 使われる場面 |
| --- | --- | --- |
| 授業名 | どの授業へ向かうか | 時間割、検索結果、案内カード |
| 担当教員 | 授業を見分ける補助情報 | 検索、授業追加 |
| 曜日・時限 | 授業の時間 | 時間割、授業追加、案内カード |
| 建物名 | どの建物へ向かうか | 時間割、キャンパスマップ |
| 階 | 建物内の何階にあるか | 時間割、案内カード |
| 教室番号 | 最終的に向かう教室 | 時間割、検索結果、案内カード |
| 目印写真 | 建物内で実際に確認する場所 | フロア案内 |

## 案内に使う画像

フロア案内では、地図だけでなく、実際の場所を確認できる写真を使う。写真を合わせて表示することで、利用者が現在地や進行方向を判断しやすくなる。

## 現在のプロトタイプで確認できること

- 時間割から授業を選び、建物案内へ進む流れを確認できる。
- 授業の追加、削除、検索の基本操作を確認できる。
- キャンパスマップ上で、選択した授業の建物を目的地として表示できる。
- フロア案内では、写真、説明文、フロアマップ、現在地マーカーを組み合わせて、段階的な案内を確認できる。

## 注意点

現在のプロトタイプでは、フロア案内は学部棟1階の104講義室への案内を例として作成している。今後、ほかの建物や教室にも対応する場合は、授業ごとに適切な建物内案内を表示できるようにする。
