## 1. 前期・後期の切り替え

**意見**:時間割の前期・後期を切り替える機能が欲しい(柳川 拓築)。付箋の画像は、「時間割の学期を設定」という見出しと「1学期/前期/春学期」「2学期/後期/秋学期」の 2 つの選択肢を並べた画面で、「学期変更は、アプリの設定からも可能です」と添えてある。

**現状**:時間割画面のヘッダーにある「2026年度 前期」は固定の文字で、切り替えられない([Timetable.tsx](../src/app/components/Timetable.tsx))。講義のデータ(`Course` 型、[types.ts](../src/app/types.ts))と授業一覧([catalog.ts](../src/app/data/catalog.ts))には学期の項目がなく、時間割は 1 つしか持てない。

**変更後の仕様**:

| 項目 | 内容 |
| --- | --- |
| 入口 | 時間割画面のヘッダーの「2026年度 前期」を押せるボタンにし、押すと学期を選ぶ画面を開く |
| 学期の選び方 | 「前期」「後期」の 2 つから 1 つを選ぶ |
| 時間割 | 学期ごとに別の時間割を持つ。切り替えると、その学期に登録した講義だけを表示する |
| 授業を検索/登録する | 今表示している学期の授業だけを検索対象にする |
| 切り替えたとき | 「時間割を後期に切り替えました」と画面下に表示し、読み上げる(既存の通知と同じ仕組み) |

**データの変更**:`Course` 型と授業一覧のデータに `semester`(前期/後期)を追加する。ダミーの授業一覧(現在 94 件)は前期・後期それぞれに作る。

**未確定事項**:

- 学期の呼び方。付箋の画像は「1学期/前期/春学期」と 3 通りを併記している。画面上で 1 つに決めるか、併記のままにするか。
- 付箋の画像は画面下から出るシート(ボトムシート)だが、2026-10-20 の決定で「ボトムアップのメニューは使わない」としている。学期の選択は、別画面か画面中央のダイアログのどちらにするか。
- 「アプリの設定からも変更できる」と書かれているが、設定画面は今のアプリにない。設定画面を新しく作るかどうか。

## 2. 教室名を編集するボタン

**意見**:教室名の編集ボタンが欲しい(s251291)。

**現状**:講義の内容(講義名・担当教員・曜日・時限・棟・階・教室番号)を変えるには、時間割画面の「削除」ボタンで削除モードに入り、講義を押して「講義を編集」画面を開く必要がある([CourseEditScreen.tsx](../src/app/components/CourseEditScreen.tsx))。ボタンの名前が「削除」なので、編集もここからできることが分からない。

**変更後の仕様**:No.6 とまとめて、ボタン名を「削除・編集」にする(No.6 を参照)。編集画面の項目は今のまま変えない。

**未確定事項**:意見が「教室名だけを直すボタン」を求めているのか、「編集の入口が分かりにくい」ことを指しているのか、s251291 に確認する。教室名だけを直す専用のボタンが必要なら、講義を押したときの選択肢に「教室名を変更」を足す案がある。

## 3. 左上の「検索/登録」ボタンを外す

**意見**:左上の「教室を検索/登録」キーは要らない(s251291)。

**現状**:時間割画面のヘッダーには、左に「授業を検索/登録する」(青の塗り)、右に「教室・棟を探す」(薄い青)の 2 つのボタンがある。「教室を検索/登録」という名前のボタンはない。また、時間割の空きコマ(「+」のマス)を押しても「授業を検索/登録する」画面が開く。

**変更後の仕様(案)**:左の「授業を検索/登録する」ボタンを外し、授業の登録は空きコマを押す操作だけにする。右の「教室・棟を探す」はヘッダーに残す。

**未確定事項**:付箋の「教室を検索/登録」がどちらのボタンを指すか、s251291 に確認する。左のボタンを外すと、曜日・時限を決めずに授業名や教員名だけで探す入口がなくなる(空きコマから開くと、その曜日・時限が選ばれた状態になるため)。この入口をなくしてよいかも合わせて決める。

## 4. 時間割のマスで、棟と教室の表示を区切る

**意見**:時間割の表示のところの学部棟、教室名の表示欄を区切ったほうがいい(s251291)。

**現状**:時間割の各マスには、講義名の下に「研究棟A 1F」「105号室」を続けて表示している。マスの幅は約 60px(画面幅 390px のとき)で、「研究棟A 1F」が「研究棟A」と「1F」で折り返す場合がある。棟と教室の間に区切りがないため、どこまでが棟名か分かりにくい。

**変更後の仕様**:

| 項目 | 内容 |
| --- | --- |
| 表示の順番 | 1 行目:講義名、2 行目:棟名、3 行目:階と教室番号(例:「1F 105」) |
| 区切り | 講義名と、棟・教室の間に細い線を入れる |
| 読み上げ | 今と同じく「講義名 棟 階 教室」の順で読み上げる |

文字の大きさ(講義名 11px、棟・教室 10px)とコントラスト(4.5:1 以上)は今のまま変えない。

## 5. 埋まっているコマへの上書き登録

**意見**:講義の登録で、埋まっているところを上書きできない(s251203)。

**現状**:「授業を検索/登録する」画面では、すでに講義があるコマの授業に「このコマは埋まっています」と表示し、「登録」ボタンを出さない([CourseSearchScreen.tsx](../src/app/components/CourseSearchScreen.tsx))。最初は「空きコマのみ」がオンなので、埋まっているコマの授業は表示もされない。入れ替えたいときは、一度時間割で削除してから登録し直す必要がある。

**変更後の仕様**:

| 項目 | 内容 |
| --- | --- |
| ボタン | 埋まっているコマの授業にも「置き換える」ボタンを出す(空きコマの授業は今のまま「登録」) |
| 確認 | 押したら確認ダイアログを出す。例:「月曜 1限の『マーケティング・マネジメント』を『日本史概説』に置き換えますか? 元の講義は時間割から消えます。」 |
| ダイアログの操作 | 削除の確認ダイアログと同じ(最初のフォーカスは「キャンセル」、Esc で閉じる) |
| 結果の通知 | 「月曜 1限を『日本史概説』に置き換えました」と画面下に表示し、読み上げる |
| 「空きコマのみ」 | 今のまま最初はオンにする。埋まっているコマの授業を出すには、チェックを外す |

## 6. 「削除」ボタンを「削除・編集」に改名

**意見**:削除ボタンの名前を「削除・編集」にした方が分かりやすい(sora hamamoto)。

**現状**:時間割画面のボタン名は「削除」で、押すと「削除を終える」に変わる(2026-10-20 にコミット e1fc7aac で「編集」から変更)。このモードでは、講義の右上の×で削除、講義を押すと編集ができる。

**変更後の仕様**:

| 項目 | 内容 |
| --- | --- |
| ボタン名 | 押す前:「削除・編集」、押した後:「削除・編集を終える」 |
| 案内文 | 「削除・編集モード:講義の右上の×で削除、講義を押すと内容を変更できます」 |
| README | 時間割の仕様の説明を「削除・編集」に合わせて直す |

No.2(教室名の編集ボタン)の意見も、このボタン名の変更で編集の入口が分かるようにして対応する。

## 7. 教室検索の結果に棟名を出す

**意見**:教室検索で、棟の名前が一番上に出て、その下に教室番号だけが並ぶ形なので、どこの棟の教室か判断しづらかった(s251265)。

**現状**:「教室・棟を探す」画面の検索結果は、棟ごとに見出し(例:「研究棟A 棟を地図で見る」)を出し、その下に「103号室 1F」のように教室番号だけを並べている([CampusSearchScreen.tsx](../src/app/components/CampusSearchScreen.tsx))。研究棟A で検索すると 17 件並び、下にスクロールすると見出しが画面の外に出て、棟名が見えなくなる。

**変更後の仕様**:

| 項目 | 内容 |
| --- | --- |
| 教室の行 | 1 行目に「研究棟A 103号室」のように棟名と教室番号を続けて出し、2 行目に「1F」と、時間割で使っている授業名を出す |
| 棟の見出し | 「棟を地図で見る」のボタンとして今のまま残す |
| 読み上げ | 「研究棟A 103号室、1F。地図で見る」の順にする |
